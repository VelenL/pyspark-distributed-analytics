# Data

The original course datasets are not redistributed in this repository.

The notebooks expect these files in this directory:

```text
trump_tweets.txt
positive-words.txt
negative-words.txt
stop-words.txt
useless-words.txt
project_data_real_estate_toulouse_and_suburbs.csv
```

The tweet dataset contained approximately 58,000 lines. The real-estate dataset contained approximately 80,000 rows and used a semicolon-separated schema equivalent to:

```text
SaleDate;SaleType;Price;PostCode;City;NbRooms;NbLots;ResidenceType;LivingArea;LandArea
```

Use only data you are authorised to access. Update `DATA_DIR` in the notebooks if you store the files elsewhere.
